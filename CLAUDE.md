# justbeingmercedes

Static one-page site for Mercedes Asare at justbeingmercedes.com: plain HTML + CSS in `public/`, no framework, no build step, no scripts except Google Fonts. It deploys to the Cloudflare Pages project `justbeingmercedes`: every push to `main` publishes the `staging` preview, and justbeingmercedes.com is published only from a sha the nightly browser checks (`e2e.yml`, 08:20 UTC + dispatch) have passed — `deploy.yml` fires on that success; promote by hand with `gh workflow run e2e.yml --ref main` (RUNBOOK.md, Deploy). The merge gate (`validate.yml`) is `npm run validate:static` + `npm test`, no browser. The page is ONE screen: it must not scroll at 1440×900 or 1280×800, and at most one short scroll on a 390×844 phone; `npm run validate` (scripts/validate.mjs, Playwright; `--static` is the browserless merge-gate half) enforces this plus the collab mailto, the three social links, one `<h1>`, alt text, the 400 KB image cap, 5–8 gallery photos each opening a full-size CSS-only `:target` lightbox, and no `<script>` at all. Gallery photos come from `photos-src/gallery.json` via `scripts/build-images.py`, which regenerates the marked blocks in index.html. Photos load through `/photos/<slot>` (Pages Function: R2 upload if present, else 302 to `public/assets/`); Mercedes replaces them at `/upload` with no password by the owner's choice, and also edits her bio, the short line above her name and a description (alt text) per replaced photo there; those live in R2 `site.json` and `functions/index.js` writes them into the static page with HTMLRewriter (plus og:image following the hero), falling back to the static page if R2 fails. Branch previews use `STORE_PREFIX=preview/` (wrangler.toml `[env.preview]`) so they never touch live data. `npm test` is the upload/bio e2e. Every bio fact must come from her public Instagram, TikTok, LinkedIn or Linktree. Operating steps are in RUNBOOK.md.
